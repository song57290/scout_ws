## 2-2. “fire” 감지 이벤트 & 픽셀 좌표 퍼블리시 추가

**왜?**
다음 단계(3D 좌표화)에서 (u,v) 픽셀을 받아 깊이로 Z를 구해 map 좌표로 바꿔야 한다.

**어디를 바꾸나?**

* `__init__` 에 퍼블리셔 2개 추가
* 감지 루프에서 “fire”(혹은 네 모델의 클래스명)에 해당하면 **중앙 픽셀 (u,v)** 발행, **이벤트(Bool)** 1회 트리거

```python
# 상단 import
from std_msgs.msg import Bool
from geometry_msgs.msg import Point32

# __init__ 안
self.pub_fire_event = self.create_publisher(Bool, '/fire/event', 1)
self.pub_fire_pixel = self.create_publisher(Point32, '/fire/pixel', 1)
self.fire_frames = 0
self.fire_detected = False
CONF_NOTIFY = 0.5  # 신뢰도 임계, 필요 시 조정

# 감지 루프 내부(각 det마다)
name = self.names[c].lower()
if name in ('fire','flame','smoke'):  # 학습된 클래스명에 맞춰 조정
    if float(conf) > CONF_NOTIFY:
        self.fire_frames += 1
        x1,y1,x2,y2 = [int(v) for v in xyxy]
        u = (x1+x2)//2
        v = (y1+y2)//2
        self.pub_fire_pixel.publish(Point32(x=float(u), y=float(v), z=float(conf)))

        if self.fire_frames >= 2 and not self.fire_detected:
            self.pub_fire_event.publish(Bool(data=True))
            self.fire_detected = True
    else:
        self.fire_frames = max(0, self.fire_frames - 1)

# 프레임에 fire 없을 때
if len(det) == 0:
    self.fire_frames = max(0, self.fire_frames - 1)
    if self.fire_frames == 0:
        self.fire_detected = False
```

# 3단계. 화점 3D 좌표 산출 노드 추가 (`fire_localizer.py`)

**역할**

* `/fire/pixel`(u,v) + `/depth_camera/depth/image_raw` + `/depth_camera/camera_info`로 **카메라 좌표 (Xc,Yc,Zc)** 복원
* `tf2`로 **map 좌표**로 변환해서 `/fire/pose_map` 퍼블리시

**어디에 파일을 두나?**
`waypoint_follower.py`가 있는 **같은 패키지의 `scripts/`** 폴더가 편하다. (예: `scout_gazebo_sim/scripts/`)

### 새 파일: `scripts/fire_localizer.py`

```python
#!/usr/bin/env python3
import rclpy, numpy as np
from rclpy.node import Node
from sensor_msgs.msg import Image, CameraInfo
from geometry_msgs.msg import Point32, PoseStamped
from cv_bridge import CvBridge
import image_geometry
import tf2_ros, tf2_geometry_msgs

class FireLocalizer(Node):
    def __init__(self):
        super().__init__('fire_localizer')
        self.br = CvBridge()
        self.model = image_geometry.PinholeCameraModel()
        self.have_info = False
        self.depth = None
        # topic 이름은 1단계에서 정리한 그대로
        self.sub_info  = self.create_subscription(CameraInfo, '/depth_camera/camera_info', self.cb_info, 10)
        self.sub_depth = self.create_subscription(Image, '/depth_camera/depth/image_raw', self.cb_depth, 10)
        self.sub_px    = self.create_subscription(Point32, '/fire/pixel', self.cb_px, 10)
        self.pub_pose  = self.create_publisher(PoseStamped, '/fire/pose_map', 1)

        self.tfbuf = tf2_ros.Buffer()
        self.tflis = tf2_ros.TransformListener(self.tfbuf, self)

    def cb_info(self, msg: CameraInfo):
        self.model.fromCameraInfo(msg)
        self.info_msg = msg
        self.have_info = True

    def cb_depth(self, msg: Image):
        self.depth = self.br.imgmsg_to_cv2(msg, desired_encoding='passthrough')

    def cb_px(self, p: Point32):
        if not (self.have_info and self.depth is not None):
            return
        u, v = int(p.x), int(p.y)
        if not (0 <= v < self.depth.shape[0] and 0 <= u < self.depth.shape[1]):
            return
        d = float(self.depth[v, u])
        if d <= 0.0 or np.isnan(d):
            return
        if self.depth.dtype == np.uint16:  # 16UC1 -> meter
            d = d / 1000.0

        # optical frame 기준 3D 복원
        Xr, Yr, Zr = self.model.projectPixelTo3dRay((u, v))
        scale = d / np.sqrt(Xr*Xr + Yr*Yr + Zr*Zr)
        Xc, Yc, Zc = Xr*scale, Yr*scale, Zr*scale

        ps = PoseStamped()
        ps.header.frame_id = self.info_msg.header.frame_id or 'depth_camera_optical_frame'
        ps.header.stamp = self.get_clock().now().to_msg()
        ps.pose.position.x = Xc
        ps.pose.position.y = Yc
        ps.pose.position.z = Zc
        ps.pose.orientation.w = 1.0

        try:
            t = self.tfbuf.lookup_transform('map', ps.header.frame_id, rclpy.time.Time())
            ps_map = tf2_geometry_msgs.do_transform_pose(ps, t)
            self.pub_pose.publish(ps_map)
        except Exception as e:
            self.get_logger().warn(f'TF transform failed: {e}')

def main():
    rclpy.init()
    n = FireLocalizer()
    rclpy.spin(n)
    n.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

# 4단계. 순찰 on/off 제어: `waypoint_follower.py`에 `/auto_mode` 구독 추가

**왜?**
화재 발생 시 순찰을 **일시 중지**하고, 대응 후 **재개**해야 한다.

**어디를 바꾸나?**
`waypoint_follower.py` 내부에 Bool 구독자와 플래그를 추가하고,

* `auto_mode == False`면 새 목표를 시작하지 않도록
* 이미 진행 중이면 취소(선택)하도록

### 패치 스니펫

```python
from std_msgs.msg import Bool

class WaypointFollower(Node):
    def __init__(self):
        ...
        self.auto_mode = True
        self.sub_auto = self.create_subscription(Bool, '/auto_mode', self.cb_auto, 1)
        ...

    def cb_auto(self, msg: Bool):
        self.auto_mode = bool(msg.data)
        if not self.auto_mode:
            try:
                self.navigator.cancelTask()
            except Exception:
                pass

    def follow_loop(self):
        while rclpy.ok():
            rclpy.spin_once(self, timeout_sec=0.1)
            if not self.auto_mode:
                continue  # 대기
            # 평소처럼 웨이포인트 하나씩 고!
            ...
```

**무엇이 변하나? (확인)**

```bash

# 순찰 재개
ros2 topic pub /auto_mode std_msgs/Bool "{data: true}" --once
```

# 5단계. 코디네이터 노드 추가 (`fire_response_coordinator.py`)

**역할**

* `/fire/event` 수신 → 순찰 중단(`/auto_mode=false`)
* Nav2로 **(0,0,0)** 복귀
* **그리퍼 픽업 시퀀스** 수행
* `/fire/pose_map` 좌표로 이동
* **순찰 재개**(`/auto_mode=true`)

### 새 파일: `scripts/fire_response_coordinator.py`

```python
#!/usr/bin/env python3
import rclpy, time
from rclpy.node import Node
from std_msgs.msg import Bool, Float64MultiArray
from geometry_msgs.msg import PoseStamped
from robot_navigator import BasicNavigator, TaskResult  # 이미 사용 중인 클래스

class FireCoordinator(Node):
    def __init__(self):
        super().__init__('fire_coordinator')
        self.nav = BasicNavigator()
        self.nav.waitUntilNav2Active()

        self.pub_auto = self.create_publisher(Bool, '/auto_mode', 1)
        self.pub_grip = self.create_publisher(Float64MultiArray, '/gripper_controller/commands', 1)
        self.pub_lift = self.create_publisher(Float64MultiArray, '/gripper_height_controller/commands', 1)

        self.sub_evt  = self.create_subscription(Bool, '/fire/event', self.cb_event, 10)
        self.sub_pose = self.create_subscription(PoseStamped, '/fire/pose_map', self.cb_pose, 10)

        self.fire_pose = None
        self.handling  = False

        # 순찰 시작 보증
        self.pub_auto.publish(Bool(data=True))
        self.get_logger().info('PATROL started.')

    def cb_pose(self, msg: PoseStamped):
        self.fire_pose = msg

    def cb_event(self, msg: Bool):
        if not msg.data or self.handling:
            return
        self.handling = True
        self.get_logger().warn('FIRE detected. Starting response sequence...')
        # 1) 순찰 중지
        self.pub_auto.publish(Bool(data=False))
        try: self.nav.cancelTask()
        except Exception: pass

        # 2) (0,0,0) 복귀
        home = PoseStamped()
        home.header.frame_id = 'map'
        home.header.stamp = self.nav.get_clock().now().to_msg()
        home.pose.orientation.w = 1.0
        if not self._go_to(home):
            self.get_logger().error('Failed to return home.')
            return self._resume()

        # 3) 소화기 픽업(값은 너희 컨트롤 범위에 맞게 조정)
        self._pickup_extinguisher()

        # 4) 화재 좌표로 이동
        if self.fire_pose and self._go_to(self.fire_pose):
            self.get_logger().info('Reached fire location.')
        else:
            self.get_logger().warn('No fire pose or failed to reach.')

        # 5) 순찰 재개
        self._resume()

    def _go_to(self, goal: PoseStamped):
        self.nav.goToPose(goal)
        while not self.nav.isTaskComplete():
            time.sleep(0.1)
        return self.nav.getResult() == TaskResult.SUCCEEDED

    def _pickup_extinguisher(self):
        self.get_logger().info('Gripper: lowering...')
        self.pub_lift.publish(Float64MultiArray(data=[-0.10]))
        time.sleep(1.5)
        self.get_logger().info('Gripper: closing...')
        self.pub_grip.publish(Float64MultiArray(data=[0.8]))
        time.sleep(1.0)
        self.get_logger().info('Gripper: lifting...')
        self.pub_lift.publish(Float64MultiArray(data=[0.10]))
        time.sleep(1.0)

    def _resume(self):
        self.pub_auto.publish(Bool(data=True))
        self.handling = False
        self.get_logger().info('PATROL resumed.')

def main():
    rclpy.init()
    n = FireCoordinator()
    rclpy.spin(n)
    n.destroy_node()
    rclpy.shutdown()

if __name__=='__main__':
    main()
```

**실행 권한**

```bash
chmod +x scripts/fire_response_coordinator.py
```

**무엇이 변하나? (확인)**

* 불 감지 → 순찰이 멈추고, 로봇이 (0,0,0)으로 이동, 그리퍼 동작 후 `/fire/pose_map` 위치로 이동 → 다시 순찰 재개.

> ⚠️ 그리퍼 토픽/값은 실제 컨트롤러에 맞게 수치 재조정 필요. (`ros2 topic echo /gripper_controller/commands`로 범위 파악)

# 6단계. 런치 통합 (`office_scout_mini.launch.py`)

패키지 구조를 모르는 상태에서도, **ExecuteProcess로 python 스크립트 직접 실행**하면 빠르다. (후에 `entry_points`로 정식 노드 등록해도 OK)

### 추가 스니펫

```python
from launch.actions import ExecuteProcess, TimerAction
import os

this_pkg = os.path.dirname(__file__)
scripts_dir = os.path.join(os.path.dirname(this_pkg), 'scripts')

yolo_path    = os.path.join(scripts_dir, 'yolo_fire_detection.py')          # 이미 있음
localizer    = os.path.join(scripts_dir, 'fire_localizer.py')               # 3단계
coordinator  = os.path.join(scripts_dir, 'fire_response_coordinator.py')    # 5단계

yolo_proc = ExecuteProcess(cmd=['python3', yolo_path], output='screen')
localizer_proc = ExecuteProcess(cmd=['python3', localizer], output='screen')
coordinator_proc = ExecuteProcess(cmd=['python3', coordinator], output='screen')

ld.add_action(TimerAction(period=12.0, actions=[yolo_proc]))
ld.add_action(TimerAction(period=12.5, actions=[localizer_proc]))
ld.add_action(TimerAction(period=13.0, actions=[coordinator_proc]))
```

## 자주 나는 실수 & 팁

* **RGB/Depth 토픽 혼동**: YOLO는 반드시 `/depth_camera/image_raw`(RGB)를 봐야 한다.
* **camera\_info frame\_id**: RealSense처럼 `..._optical_frame`이면 그대로 쓰고, 비어있으면 1단계에서 만든 `depth_camera_optical_frame`로 강제해도 된다.
* **TF 누락**: `map→odom→base_link→...→depth_camera_optical_frame` 경로가 끊기면 좌표 변환 실패. `view_frames` 꼭 확인.
* **그리퍼 값**: 실제 컨트롤러 범위/단위에 맞게 수치 조정(라디안/미터/정규화 여부).
* **(0,0,0) 접근성**: 맵의 원점이 가구/벽이면 목표를 약간 띄운 좌표(예: x=0.3)로 쓰는 게 안전.

원하는 흐름(순찰→감지→좌표저장→복귀→픽업→화점복귀→순찰재개)을 **위 순서대로 한 단계씩** 반영하면 바로 붙는다.
우선 **1단계 xacro 수정**부터 해보고, 결과(토픽/TF) 확인되면 다음 단계로 넘어가자. 필요하면 각 단계 코드 조각을 네 파일 구조에 맞게 더 구체적으로 맞춰줄게.
